A one-line rename for Mercury: "The Intern". Mercury is the closest planet to the Sun — closest to the boss — finishes a whole year in just 88 days, and is the smallest, most overlooked planet, so it still gets no credit. Three Mercury-only traits earn the name in a single line. Running main.py writes the line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
